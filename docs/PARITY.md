# Desktop parity matrix

Pinned Zeron rev `853872d` (engine v0.2.72). "Desktop source" paths are
relative to the pinned clone `../_ref/zeron`; `node app/scripts/check-parity-paths.mjs`
(npm script `parity:check`) verifies every cited path exists.

**Legend** — the Status column uses exactly these tokens:

- `verified` — exercised against the real edge/engine in `e2e:windows`
  ([evidence/e2e-report.md](evidence/e2e-report.md)) **or** pure logic fully
  covered by unit tests with no device dependency.
- `implemented-unverified` — code exists; needs a device/Mac build, a live
  host with the right state, or a real agent CLI to confirm end-to-end.
- `requires-host-edge-change` — needs the named patch in
  `patches/zeron-edge/` deployed on the edge.
- `blocked` — concrete blocker named in the row.
- `not-started` — not implemented.

Row counts: **verified 44 · implemented-unverified 26 ·
requires-host-edge-change 6 · blocked 7 · not-started 15**
