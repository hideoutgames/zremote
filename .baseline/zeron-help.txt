Multi-device controller for coding agents

Usage: zeron.exe [URL] [COMMAND]

Commands:
  headless  Run the engine without a UI (local-only unless a saved session enables sync)
  login     Sign in and enable sync on the next engine start
  logout    Remove the saved session and return to local-only on the next start
  status    Show workspace mode, optional auth, and engine status
  sync      Live sync introspection from the running engine: per-room connection state, last pushed-frame/ack ages, rejoin/probe/resync counters
  daemon    Manage `zeron headless` as a background service (launchd / systemd --user)
  update    Check for a newer release and apply it (download → verify → swap → service restart). `--check` only reports (exits 1 when one is available)
  help      Print this message or the help of the given subcommand(s)

Arguments:
  [URL]  Open a Zeron conversation URL

Options:
  -h, --help     Print help
  -V, --version  Print version
