Vendored engine-free Zeron peer client and transcript core.

Source: https://github.com/zeronsh/zeron
Revision: b42fc2b8fbf247dd92796c2917f277535cea91ac (v0.2.101).
License: MIT; see LICENSE.

Only client, mobile, proto, doc, sync, rpc, text, markdown, syntax and the data-only file-icon manifest are included. No host engine, terminal runner or desktop UI crate is linked. Local changes add CreateRepo and latest-turn-diff peer APIs over existing host methods and a bounded transcript projection for portable UI. Host behavior is unchanged.
